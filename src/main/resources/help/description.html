A standalone tool window for browsing and running the Gradle tasks of the opened project. It reads what the IDE has already imported — it never triggers a Gradle sync of its own.

  • Three view modes. Default rebuilds the IDE's own Gradle view but turns the group rows into a folder tree; Sort lists the full group paths alphabetically; Nested builds the folder hierarchy from slash-separated task groups.
  • An optional module level on top of Sort and Nested, so tasks of the same name in different subprojects stay apart. Tasks always run with their qualified path.
  • Hide what you never use — per node, per module, and per view mode if you want. Show Hidden brings them back greyed out.
  • Own icons per group, folder or task, read from the project directory, with a dark variant picked up automatically.
  • Run, Debug and Run with Coverage from the context menu, plus Modify Run Configuration — the same actions the original view offers.

Expand state, icons, hidden nodes and the module toggle live in two YAML files inside the project: a team default that is checked in, and personal overrides on top. The Configuration tab explains where they are and how they are written.
