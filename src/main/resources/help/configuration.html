Where the configuration lives

Everything this view remembers — expand state, custom icons, hidden nodes and the module toggle — is stored in two YAML files inside the opened project. Click a path to open it.

Team default    {{defaultFileShort}}
Checked into version control, never overwritten by the plugin.
Personal overrides    {{customFileShort}}
Written automatically, takes precedence, and records only what deviates from the default.
Icons    {{iconsDirShort}}
Image files referenced by name from either YAML file.

The toolbar's Reset to Default deletes the personal file, so the team default applies again. Hand edits to either file are picked up on the next refresh — no IDE restart needed.

Shape of a file

The top level has exactly four keys. Group paths and task names live in separate namespaces, so a task called build and a group called build never affect each other.

What a node entry may contain

expanded    Expand state. A bare true/false instead of a mapping is the short form for exactly this field.
icon    File name relative to the icons directory. A sibling <name>_dark.<ext> is preferred automatically under dark themes. A missing file falls back to the built-in icon and logs a warning.
hidden    Hides the node. The only field inherited along a path: a hidden folder takes its whole subtree with it, and a more precise entry can take it back.
modes    The same fields again, but only for default, sort or nested.

Which entry wins

Resolved per node and per field, in this order:

  • module-scoped before module-independent,
  • mode-specific before all-modes,
  • personal file before team default,
  • then the built-in default (expanded, plugin icon, visible).

hidden uses the same order with one criterion in front: how precisely the entry names the node — task, then folders from the inside out, then module.

Folder paths are the slash-separated group paths shown in the tree (docker/server/gui). A folder that is compacted into one row keeps its full path as the key, so an entry for a compacted-away intermediate node has no effect. The Tasks node of the Default view has no key at all and follows its module.
