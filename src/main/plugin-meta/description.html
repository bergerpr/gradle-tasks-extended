A standalone tool window for the Gradle tasks of the opened project, with three view modes: Default rebuilds the IDE's own Gradle view but turns the group rows into a folder tree, Sort lists the full group paths alphabetically, and Nested builds a folder hierarchy from slash-separated task groups. An optional module level can be switched on top of Sort and Nested.

Nodes can be hidden per module and per view mode, groups and tasks can carry their own icons, module, group and folder nodes can carry their own tooltip, and Run, Debug and Run with Coverage are available from the context menu. The configuration can also add rows of its own: an entry with execute shows an existing Gradle task in a second, freely named group without creating a Gradle task.

Expand state, icons, tooltips and hidden nodes are stored in two YAML files inside the project: a team default that is checked in, and personal overrides on top. The toolbar's gear opens the team default and reloads the view after hand edits.

Screenshots and build details are in the plugin's own info dialog: the tool window's toolbar, the button next to the gear.

Built for private use; not distributed through the JetBrains Marketplace.
